## About

A web-based marketplace where buyers can check an antique's origin, ownership history, condition and authenticity before deciding to buy.

## Features

* Browse a list of antiques with price, era and origin
* Search by name, era or origin
* Filter by category and authenticity status
* Full provenance record for every item (origin, ownership history with sources, condition report, authenticity checks)
* Verified and pending authenticity labels
* Gaps in ownership history shown as "Not documented"
* Question form to ask about an item
* Simple, responsive design

HTML, CSS, JavaScript
